## 🛠️ Mini Project – Technologies & Concepts Used

This portfolio is built strictly using core web fundamentals without any JavaScript libraries, Bootstrap, or external web frameworks.

| Category | Concepts & Technologies Applied |
| :--- | :--- |
| **Markup & Structure** | • HTML5<br>• Semantic HTML tags (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`, `<table>`, `<form>`) |
| **Styling & Layout** | • CSS3<br>• CSS Flexbox (Navigation, Hero layout, Buttons, Social links)<br>• CSS Grid (Skills Grid, Projects Grid, Contact Layout) |
| **Interactivity & UI** | • Hover Effects<br>• CSS Transitions & Keyframe Animations<br>• Pure CSS Progress Indicators & Floating Badges |
| **Media & Content** | • Profile Images & Dashboard Visual Previews<br>• Ordered & Unordered Lists (`<ul>`, `<ol>`)<br>• Navigation & Smooth Anchor Hyperlinks (`#about`, `#skills`, etc.) |
| **Data Presentation** | • Custom Styled HTML5 Tables (`<table>`, `<thead>`, `<tbody>`, Zebra striping, Hover states) |
| **User Communication**| • Functional HTML5 Contact Form (`<form>`, `<input>`, `<select>`, `<textarea>`, `<button>`, Required HTML Validation) |
| **Responsiveness** | • Media Queries (`@media`) for 100% Mobile, Tablet, and Desktop Responsiveness |
| **Repository Standards**| • GitHub Repository Structure<br>• GitHub Pages Deployment Ready<br>• README.md Documentation<br>• MIT License |

> **Note**: Strictly 0 lines of JavaScript, 0 Bootstrap dependencies, and 0 external frameworks used.

## 📋 Features Overview

1. **Sticky Glassmorphism Header Nav**: Smooth CSS scrolling navigation bar with custom gradient branding and a direct "Download Resume PDF" action.
2. **Hero Section**: Showcases Riya's avatar photo in a glowing glass card, status badge, key intro, and quick links to GitHub and LinkedIn.
3. **About Me**: Dual-column layout highlighting her professional summary, analytical background, and core capabilities.
4. **Technical Toolkit**: Grid of skill cards covering Excel (Pivot Tables, VLOOKUP), SQL (SELECT, JOIN, GROUP BY), Python (Pandas, Matplotlib), Power BI, and Data Cleaning.
5. **Experience Timeline**: Detailed timeline of her internship at the **Block Development Office (BDO), Paigu, Firozabad**.
6. **Qualifications Table**: Structured HTML5 table listing her degree at **Sharda University Agra** and secondary school certifications.
7. **Featured Projects**: Showcase cards for Data Analytics projects with visual previews and GitHub links.
8. **Certifications & Strengths**: Highlights certifications in Matlab, Python, SQL, key personal strengths, and spoken languages.
9. **Contact Form**: Semantic form with inputs for Name, Email, Subject Reason select dropdown, Message textarea, and mailto submit action.

## 🌐 Local Development & Setup

To run this portfolio locally on your computer:

1. Clone or download this repository:
   ```bash
   git clone https://github.com/riyasinghh0811-eng/riya-portfolio.git
   ```
2. Open `index.html` in any web browser (Google Chrome, Mozilla Firefox, Microsoft Edge, Safari).
3. No build tools or node packages required!
